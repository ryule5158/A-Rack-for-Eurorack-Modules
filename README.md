# Rack4Modules：3×104HP 原创 Eurorack 机箱

本项目当前设计入口为 **V0.6 稳定支撑版**。它保持 3 排 104HP、无 1U、`542 mm` 模块
安装内净宽，以及现有模块导轨、机箱、上后沿接口、VESA、提手和电源空间；当前改版重点是
把折叠脚架收敛为一个有明确双剪切承载止挡的 60°正式工作姿态。

第一次打开项目，请先看 [V0.6 零基础打开与检查说明](START_HERE_V06.md)；结构设计和样机
验收边界见 [V0.6 折叠脚架稳定性说明](docs/stability-v06.md)。

V0.5 是已经完成 `524 PASS / 15 WARNING / 0 FAIL` 的双剪切夹持 CAD 基线。该统计只证明
报告覆盖的文件、引用和离散 CAD 条件，不是连续运动、强度或实体稳定性认证。V0.5 现作为
V0.6 的已验证基线及历史版本保留；V0.4 外置/轴向外弹方案是更早历史，也继续完整保留。

## V0.6 冻结方案

- Eurorack 格式为 3 排 3U、每排 104HP，共 312HP，**没有 1U 行**；模块安装内净宽保持
  `542 mm`。
- 每侧为 `3 mm` 内侧承力框、`6.8 mm` 腿腔和 `3 mm` 外承力颊板；每侧四个
  `6.8 mm` 隔柱把内外板连成结构盒。隔柱已移出收纳腿和脚垫的理想全扫掠包络，当前
  2001 点二维筛查的最小名义净距目标不低于 `2 mm`。
- 折腿为 `6 mm 7075-T6`，主轴至脚垫中心距 `170 mm`；名义裸机总宽为 `567.6 mm`。
- 脚端为 `Ø16 × 6 mm` 氯丁橡胶（CAD 候选）圆冠，脚垫中心距桌面 `8 mm`；预计折腿旋转约
  `92.423°`，后支撑深度约 `133.770 mm`。
- 主轴为 `Ø8 × 12.8 mm` 双剪切轴；独立的 `Ø8 × 12.8 mm` 双剪切实体止挡压在
  `6 × 3 × 16 mm` 钢制脚跟承压面上，形成主要工作载荷路径。
- `Ø5 × 12.8 mm` 锁销只防止工作位意外反折，并提供收纳锁定位；它不能作为主要承载
  止挡。
- V0.6 唯一正式工作姿态为模块面相对桌面约 `60°`。

`567.6 mm` 是名义裸机宽度，不是含深盖、盖锁、阳极层、公差和密封件的运输包络。正式
出图前仍须完成最坏公差链。

## 稳定性筛查边界

在 `133.770 mm` 支撑深度下，理想居中的重心投影距前后边界各约 `66.88 mm`。以
`20 kg` 满载、`300 mm` 高处 `20 N` 操作力并对操作力取 `1.5` 安全系数筛查，需要约
`45.87 mm` 重心边界余量。满载纵向重心的当前目标是支撑深度中点附近 `±20 mm`，理论
较小侧余量约 `46.88 mm`。

该余量并不宽裕，必须装入最重目标模块、电源和线缆后实测三维重心。以单腿 `400 N`、
再取 `1.5` 倍，并按接触法向到主轴的 `28.0 mm` 止挡力臂筛查，实体止挡附近反力约为
`3.64 kN`。
这些数字只用于设计筛查，不能称为额定载荷、有限元认证或实物合格证明。

## 必须完成的实物验证

投产前至少要完成：

1. 满载及最坏偏载的三维重心测量；
2. 目标桌面上的脚垫摩擦、滑移和机械卡持/防脱试验；
3. 最不利位置和方向的 `20 N` 操作稳定试验；
4. 单腿 `400 N` 偏载并叠加 `30 N` 侧向载荷；
5. `1.5` 倍静载保持试验；
6. 至少 `10000` 次折叠循环；
7. 板厚、阳极层、孔位、轴套、销轴、隔柱和平面度的完整公差链；
8. 主轴/止挡/锁销防松与轴向防脱，以及运输振动、跌落后的功能复检。

详细验收矩阵见 [V0.6 折叠脚架稳定性说明](docs/stability-v06.md)。在这些实测完成前，
项目只能说“已按稳定支撑目标设计并进入验证”，不能说“已确保实物稳定”。

## 参考产品与原创边界

[Intellijel 7U Performance Case Gen-2 官方产品页](https://intellijel.com/shop/cases/7u/7u-performance-case-gen-2/)
和[官方手册](https://intellijel.com/downloads/manuals/7u/7u-performance-case-gen-2_manual_2026.04.13.pdf)
仅确认其采用“侧板内隐藏腿、独立弹簧 Stand Lock、两个位置”的功能组织。公开资料没有
证明其采用本项目的单角、双剪切主轴、实体止挡、销轴尺寸、材料或载荷指标。

因此，V0.6 的单一 60°正式姿态、双剪切夹层、Ø8 实体承载止挡、钢制脚跟面和 Ø5
防反折锁销，都是 Rack4Modules 针对本机箱作出的**原创工程选择**，不声称精确复制
Intellijel 的内部结构或承载能力。
