# Rack4Modules V0.3 后向窄长边接口布局

## 1. 版本定位与旧方案纠正

V0.3 接口布局以 Intellijel 7U Performance Case Gen-2 的后向窄长边为主要参考：接口、提手和未来电源入口集中布置在机箱的一条宽而窄的边缘，而不是安装在承载 VESA 支架的大面积背板上。

本版本替代此前“背板左右分置接口板”“8 个音频孔采用 2 × 4 布局”“2 个 D 型 USB 位置”和“2 个 3.5 mm AUX 接口”的接口布置思路。V0.3 不设置 USB-A、USB-B、D 型 USB 法兰和 3.5 mm AUX 专用接口，也不在大面积背板开设音频、MIDI、USB 或电源窗口。

V0.3 的目标配置为：

- 左侧：200 × 80 可换音频板，8 个 6.35 mm TRS 插座单排布置。
- 中央：约 128–140 宽的折平提手区域；按本文精确坐标计算，净区为 128。
- 右侧：150 × 80 可换数字板，3 个 5 针 DIN MIDI 插座和 1 个紧凑型 USB-C 插座单排布置。
- 最右端：50 × 80 独立电源空白板，只有面板固定孔，没有电源连接器、开关或其他功能孔。
- 机身大面积背面：仅保留 VESA 100 × 100 安装孔及必要的内部加强结构。

本文只新增 V0.3 的布局定义，不修改早期文档。若既有文档中的机身宽度、后板开孔位置或接口配置与本文不一致，V0.3 接口几何以本文为准，其他文件需由后续整体设计变更单独同步。

## 2. 全局坐标、边界与方向

### 2.1 坐标定义

采用以下右手坐标约定：

- `x`：机身宽度方向，原点位于机身中心；向右为正。
- `y`：机身正面高度方向；接口位于后向窄长边所在的上边平面，具体平面高度由整机装配决定。
- `z`：机身前后深度方向，`z = 0` 为正面一侧，`z = 110` 为大面积背面一侧。
- 后向窄长边是 `x-z` 平面，尺寸为 `542 × 110`。
- 大面积背板是 `x-y` 平面，仅设置 VESA 100 安装。

全部尺寸单位为毫米。

### 2.2 后向窄长边外轮廓

| 项目 | 数值 |
| --- | --- |
| 机身总宽度 | 542 |
| 左侧外边界 | `x = -271` |
| 右侧外边界 | `x = +271` |
| 窄长边总深度 | 110 |
| 正面边界 | `z = 0` |
| 背面边界 | `z = 110` |
| 三块可换面板共同高度范围 | `z = 15..95` |
| 所有接口中心线 | `z = 55` |

面板到窄边上下两侧各保留 15 的边缘空间。面板总分区从 `x = -264` 到 `x = +264`，与机身左右外边界分别保留 7 的名义间隙。

## 3. 总体三区布局

从左到右可划分为音频区、提手区、数字/未来电源区。其中数字板与电源空白板虽然属于同一个右侧功能区，但必须是两个相互独立、可单独更换的零件。

```text
x = -271                                                      x = +271
|                                                                      |
| 7 | AUDIO 200 | HANDLE 128 | DIGITAL 150 | POWER 50 | 7              |
|   | -264..-64 | -64..+64   | +64..+214   | +214..+264|                |
|   | 8 × TRS   | fold-flat  | 3 × DIN + C | blank    |                |
|                                                                      |
|<--------------------------- 542 overall ----------------------------->|

共同面板范围：z = 15..95
共同接口中心：z = 55
```

| 分区或零件 | 全局 `x` 中心 | 名义宽度 | `x` 范围 | `z` 范围 |
| --- | ---: | ---: | --- | --- |
| 音频可换板 | `-164` | 200 | `-264..-64` | `15..95` |
| 中央提手净区 | `0` | 128 | `-64..+64` | `15..95` |
| 数字/MIDI 可换板 | `+139` | 150 | `+64..+214` | `15..95` |
| 独立电源空白板 | `+239` | 50 | `+214..+264` | `15..95` |

上述边界为理论分区基准。数字板与电源板在 `x = +214` 处相邻；量产时必须根据表面处理、切割公差及装配方式预留实际板缝，不能把两块零件按零间隙强行装配。可采用每块物理面板向分区内缩 0.2–0.5，或设计台阶搭接，但不得改变本文定义的功能中心和接口中心线。

### 3.1 提手净区宽度说明

按照音频板右边界 `x = -64` 与数字板左边界 `x = +64` 计算，中央连续净区的准确宽度是：

```text
64 - (-64) = 128
```

因此，所选折平提手的安装耳、折叠外廓、手指操作空间和紧固件必须适配 128 的连续分区。若实际提手要求 140 或更宽安装包络，必须重新调整相邻面板宽度或中心坐标，不能直接让提手压入音频板或数字板。旧资料中约 180 的提手安装孔距不适用于本版本中央分区。

## 4. 左侧 200 × 80 音频可换板

### 4.1 面板与窗口

音频面板名义轮廓：

```text
x = -264..-64
z = 15..95
中心 = (-164, 55)
尺寸 = 200 × 80
```

后向窄长边承力板上的候选音频维护窗口：

```text
中心 = (-164, 55)
尺寸 = 180 × 60
x = -254..-74
z = 25..85
```

窗口四角应采用圆角，实际半径依据激光切割、折弯工艺和结构复核确定。该窗口只是连接器本体和内部线束的通行开口；8 个连接器专用孔只开在可换音频面板上。

### 4.2 8 个 TRS 孔的准确坐标

8 个 6.35 mm TRS 插座采用单排布置，相邻孔中心距固定为 22，整排围绕 `x = -164` 对称，孔中心统一为 `z = 55`。

| 位置 | 全局 `x` | 全局 `z` | 相对于音频板中心的 `x` |
| --- | ---: | ---: | ---: |
| AUDIO 1 | `-241` | `55` | `-77` |
| AUDIO 2 | `-219` | `55` | `-55` |
| AUDIO 3 | `-197` | `55` | `-33` |
| AUDIO 4 | `-175` | `55` | `-11` |
| AUDIO 5 | `-153` | `55` | `+11` |
| AUDIO 6 | `-131` | `55` | `+33` |
| AUDIO 7 | `-109` | `55` | `+55` |
| AUDIO 8 | `-87` | `55` | `+77` |

推荐采用轻量螺纹套筒式 TRS 插座，例如 Cliff S4 系列。该系列官方资料给出候选面板孔 `Ø11.20`，但最终孔径必须与采购的完整型号、螺纹段、垫圈及面板允许厚度一致。

22 的中心距是 V0.3 锁定的布局基准，不表示任意 6.35 mm 插座都能自动适配。必须同时核对：

- 插座本体最大宽度与相邻本体间隙。
- 紧固螺母或垫圈的外径。
- 直插或直角音频插头的外壳直径。
- 手指插拔空间。
- 焊片方向、内部 PCB 和线束弯折。

如果采购的音频插座或插头在 22 中心距下干涉，应优先更换为更紧凑的具体型号；若确需改动中心距，必须同步重新计算所有 8 个坐标及 200 宽面板边距。

### 4.3 音频板固定孔

音频可换板采用 4 个 M3 固定点，参考板孔为 `Ø3.4`，承力板侧采用 M3 压铆螺母、螺母座或等效紧固件。

```text
x = -258, -70
z = 20, 90
```

展开后共 4 个孔：

```text
(-258, 20)  (-70, 20)
(-258, 90)  (-70, 90)
```

固定孔位于接口中心线上下两侧，不与 8 个 TRS 插座共线。

## 5. 中央折平提手区

中央提手分区的全局中心为 `(0, 55)`，名义范围：

```text
x = -64..+64
z = 15..95
```

该区域不设置音频、MIDI、USB 或电源接口。提手折平时不得压住相邻面板固定螺钉，提起时不得扫过左右插座和已插入的线缆。

提手的以下尺寸在供应商料号确定前不冻结：

- 实际握把长度和安装耳外廓。
- 左右固定孔中心距。
- 固定孔直径和螺钉规格。
- 折平后的高度与背面接触条件。
- 提起时的旋转角、握持空间和内部加强件。

提手载荷应通过窄长边加强梁或局部加强板传递，不能只由相邻可换音频板、数字板或单层薄铝板承担。

## 6. 右侧 150 × 80 数字/MIDI 可换板

### 6.1 面板与窗口

数字面板名义轮廓：

```text
x = +64..+214
z = 15..95
中心 = (+139, 55)
尺寸 = 150 × 80
```

后向窄长边承力板上的候选维护窗口：

```text
中心 = (+139, 55)
尺寸 = 132 × 60
x = +73..+205
z = 25..85
```

3 个 DIN 和 1 个 USB-C 均位于同一排，中心线为 `z = 55`。

### 6.2 3 个 DIN 和 USB-C 的准确中心坐标

| 接口 | 全局 `x` | 全局 `z` | 备注 |
| --- | ---: | ---: | --- |
| MIDI IN | `+87` | `55` | 180° 排列、5 针 DIN 面板母座 |
| MIDI OUT | `+121` | `55` | 与前一个 DIN 中心距 34 |
| MIDI THRU | `+155` | `55` | 与前一个 DIN 中心距 34 |
| USB-C | `+191` | `55` | 紧凑型 USB-C；最终专用开孔和耳位待定 |

3 个 DIN 插座的中心距为 34；第三个 DIN 与 USB-C 中心距为 36。上述坐标定义连接器中心，不自动冻结 USB-C 矩形口、螺钉耳孔或连接器具体料号。

### 6.3 DIN 候选孔型

候选器件可参考 REAN NYS325：

- 中心主孔候选值：约 `Ø15`。
- 左右固定耳候选中心距：`22.2`。
- 正面圆形包络参考：约 `Ø19`。
- 固定耳尺寸、孔径和紧固方式必须依据采购件的现行原厂图纸确认。

若固定耳沿 `x` 方向展开，每个 DIN 位置的理论耳孔中心为：

| DIN 位置 | 左耳 `x` | 右耳 `x` | 耳孔 `z` |
| --- | ---: | ---: | ---: |
| MIDI IN，中心 `+87` | `+75.9` | `+98.1` | `55` |
| MIDI OUT，中心 `+121` | `+109.9` | `+132.1` | `55` |
| MIDI THRU，中心 `+155` | `+143.9` | `+166.1` | `55` |

这些耳孔中心只适用于固定耳中心距确实为 22.2 且安装方向与本表一致的实际器件。若选择板载 DIN、不同品牌 DIN 或竖向固定耳版本，必须重新生成面板孔位，不能沿用本表。

### 6.4 USB-C 最终料号与耳孔复核

V0.3 采用一个紧凑型 USB-C 插座，中心固定为 `(191, 55)`，不使用旧方案的 Ø24 Neutrik D 型开口，也不新增 USB-A 或 USB-B。

USB-C 插座的下列尺寸暂不冻结：

- USB-C 正面矩形开口的宽、高及圆角。
- 左右安装耳之间的中心距。
- 安装耳孔径、螺钉规格和头部空间。
- 前装、后装或 PCB 固定方式。
- 面板允许厚度。
- 插座尾部、内部短线与插头的安装深度。
- USB 屏蔽壳与机箱之间的绝缘或接地方式。

在未选定连接器之前，SolidWorks 可在 `(191, 55)` 建立连接器中心点、参考包络和抑制状态的占位草图，但不得将经验矩形尺寸或猜测的耳孔位置直接输出为加工图。若暂不安装 USB-C，使用完整的数字板局部盲区或替换板，不在承力壳上加工专用 USB 孔。

### 6.5 数字板固定孔

数字板采用 4 个 M3 固定点，参考板孔为 `Ø3.4`：

```text
x = 70, 208
z = 20, 90
```

展开后共 4 个孔：

```text
(70, 20)   (208, 20)
(70, 90)   (208, 90)
```

面板固定孔与 DIN 固定耳属于不同功能，不能在采购件未确定前假定两者共用。

## 7. 最右侧 50 × 80 独立电源空白板

### 7.1 面板与承力板预留窗口

电源盖板名义轮廓：

```text
x = +214..+264
z = 15..95
中心 = (+239, 55)
尺寸 = 50 × 80
```

若需要保持未来可更换电源入口，承力板可预留以下隐藏式服务窗口：

```text
中心 = (+239, 55)
尺寸 = 34 × 60
x = +222..+256
z = 25..85
```

服务窗口始终由独立空白电源盖板完整遮挡。该窗口不等同于 DC 插座孔，也不等同于电源开关、IEC 市电入口或保险丝座孔。

### 7.2 电源空白板固定孔

电源空白板采用 4 个 M3 固定点，参考板孔为 `Ø3.4`：

```text
x = 219, 259
z = 20, 90
```

展开后共 4 个孔：

```text
(219, 20)  (259, 20)
(219, 90)  (259, 90)
```

“无孔电源空白板”指无电源连接器、开关、指示灯、保险丝及通风功能孔；为安装该盖板所需的 4 个 M3 固定孔不在此限制之内。

### 7.3 电源边界

以下内容均不在 V0.3 中确定：

- DC 插座中心针尺寸。
- 外置适配器电压、电流和功率。
- 是否采用 USB-PD、锁紧 DC、XLR4 或 IEC 市电输入。
- 电源开关类型和位置。
- 保护接地、保险丝、EMI 滤波及认证要求。
- 内部电源板、母线板和供电线束具体位置。

任何实际电源孔型都应通过更换该独立盖板实现，而不是重切音频板、数字板或大面积背板。

## 8. 大面积背面仅保留 VESA 100

大面积背板位于 `x-y` 平面，不再承担音频、MIDI、USB 或电源接口。

VESA 100 的四个安装孔以背板中心为基准：

```text
(-50, -50)  (+50, -50)
(-50, +50)  (+50, +50)
```

上述坐标使用背板的 `(x, y)` 局部中心坐标，不与后向窄长边的 `(x, z)` 孔位混用。安装规格为 4 × M4；实际背板通孔、铆螺母或螺柱结构应依据紧固方式另行确定。

背板上不得增加：

- 音频插板窗口。
- DIN MIDI 或 USB 专用孔。
- 电源入口或开关孔。
- 与 VESA 承力区重叠的通风槽。
- 旧方案中的左右外凸 I/O 浅盒。

背板内侧可设置 VESA 加强板和必要的连接结构，但外部仍应保持平整，以兼容显示器支架、快拆板和桌面支撑面。

## 9. 侧板脚架、盖锁与下边通风避让

### 9.1 侧板折叠脚架

折叠脚架安装在左右侧板，不安装在 VESA 背板和后向接口窄边上。脚架的旋转轴、折叠臂、止挡块和紧固件应检查以下避让：

- 左侧最靠边音频插座中心 `x = -241` 与左侧板 `x = -271` 的名义距离为 30。
- 最右侧电源空白板边界为 `x = +264`，与右侧板外边界 `x = +271` 的名义距离为 7。
- 左侧音频板最靠外固定孔中心 `x = -258`，距左侧板内边界 13。
- 右侧电源盖板最靠外固定孔中心 `x = +259`，距右侧板内边界 12。
- 脚架枢轴、螺母和加强板不得进入接口固定螺钉或音频插座本体的内部包络。
- 脚架折叠和展开时不得挤压音频线、MIDI 线、USB-C 线或未来电源线。

### 9.2 盖锁与上边角部

盖锁安装位置应与左右侧板、盖口和导轨端部协同确定。锁舌运动轨迹不得进入：

- 左侧音频板最外侧插头的插拔空间。
- 中央提手的折叠扫掠范围。
- 数字板上 USB-C 插头的外部线缆弯折空间。
- 右侧电源空白板后续可能增加的电源连接器包络。

侧板角部的盖锁加强件、脚架加强件和窄长边面板固定件不得使用同一未经复核的薄板孔群。

### 9.3 下边通风

通风槽优先布置在与接口边相对的下边窄长边，避免与上边单排接口、中央提手及 VESA 大面积背板共用结构区域。

下边通风开口应避开：

- 左右侧板连接螺钉及角部加强件。
- 折叠脚架轴座和止挡件。
- 下边盖锁与盖口密封、搭接区域。
- 下排导轨固定孔及模块安装螺钉。
- 未来电源预留空间和电源线束。

通风槽是否实际加工、开孔率、槽宽及防尘策略应在整机热设计和结构校核后确定。不能以通风孔替代 VESA 加强板或提手承力结构。

## 10. 模块净深与接口线束

V0.3 把接口移至后向窄长边后，接口尾部和线束仍可能侵入最上排模块的内部空间，因此不能只根据 110 的机身外部深度推断全部位置都具备相同模块净深。

SolidWorks 装配中至少建立以下参考包络：

- `AUDIO_CONNECTOR_KEEP_OUT`：8 个 TRS 插座本体、螺母、焊片或背板 PCB。
- `MIDI_CONNECTOR_KEEP_OUT`：3 个 DIN 插座本体、固定耳、焊片和绝缘套。
- `USB_C_KEEP_OUT`：USB-C 插座、固定耳、内部短线和弯折余量。
- `HANDLE_SWEEP`：提手折平与提起时的运动范围。
- `POWER_OPTION_KEEP_OUT`：未来电源入口、开关和内部线束的预留空间。
- `SIDE_HARDWARE_KEEP_OUT`：脚架、盖锁和侧板连接件。

Intellijel 官方手册说明，其普通模块区域、供电板区域和 Audio/MIDI 板区域的可用深度并不相同。因此本项目也必须分别标记普通区域与窄边接口区域的净深，不得在尚未完成真实连接器三维装配前宣称所有位置均可安装相同深度的模块。

## 11. 加工前制造复核

1. 确认机身窄长边外形为 `542 × 110`，中心坐标及正负方向与总装一致。
2. 检查三块面板 `z = 15..95`、接口中心线 `z = 55` 是否与前盖搭接、侧板厚度和背板位置一致。
3. 核对音频板、提手区、数字板、电源板中心分别为 `-164`、`0`、`+139`、`+239`。
4. 核对 8 个 TRS 孔是否均为单排，中心距是否逐项等于 22。
5. 核对 3 个 DIN 中心坐标是否为 `+87`、`+121`、`+155`，USB-C 中心是否为 `+191`。
6. 获取最终 TRS 插座原厂图纸，复核 `Ø11.20` 是否仍适用于实际料号及所选面板厚度。
7. 获取最终 DIN 插座原厂图纸，复核 `Ø15`、`22.2`、固定耳方向及耳孔直径。
8. 在确定 USB-C 最终型号前，不输出 USB-C 矩形开口和固定耳孔到正式加工文件。
9. 核对音频板 6 孔、数字板 6 孔、电源板 4 孔的固定点坐标、M3 螺纹方式和压铆空间。
10. 复核相邻面板的实际板缝、表面处理厚度、面板倒角和安装顺序。
11. 在大面积背板上确认仅存在 VESA 100 四孔及与其直接相关的必要结构。
12. 模拟折平提手、脚架、盖锁、下边通风、已插入线缆和盖子的全过程干涉。
13. 根据真实连接器 STEP 模型测量局部模块净深，并在图纸中明确限制区域。
14. 通过 1:1 打印样板或试制板核对插头并排插拔、手指空间及线束方向。

## 12. 验证边界

V0.3 所交付的是机械布局和候选制造尺寸，不表示以下事项已经完成：

- 平衡音频输入、平衡音频输出或线路电平转换。
- MIDI 光电隔离、MIDI OUT 驱动或 MIDI THRU 转发。
- USB-C 的 Host、Device、USB-MIDI、USB Audio、USB-PD 或充电功能。
- 电源电压、电流、开关、保护接地或安全认证。
- 提手载荷、盖锁可靠性、脚架稳定性和 VESA 承重实测。

所有专用孔位在器件采购前均属于候选值；真正可加工的冻结尺寸必须基于原厂最新图纸、实际样件和整机装配复核。
