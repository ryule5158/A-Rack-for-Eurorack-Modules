# Rack4Modules V0.6 折叠脚架稳定性设计边界

本文冻结 V0.6 折叠脚架的设计意图、载荷路径和样机验收边界。它是结构设计说明，不是
计算书、有限元报告或产品认证。

## 1. 适用范围

- 机箱格式：3 排 3U、每排 104HP，总计 312HP，**不含 1U 行**；
- 模块安装内净宽：`542 mm`；
- V0.6 唯一正式桌面姿态：模块操作面相对桌面约 `60°`；
- V0.5 的 75°姿态只作为历史 CAD 记录保留，不属于 V0.6 功能、验收或宣传范围；
- 电源、接口、VESA、上方提手和模块导轨边界沿用现有机箱；本文同时记录为折叠腿新增的
  V0.6 运输盖让位处理，避免把运输盖干涉误认为“已知包装”。

## 2. 截面和承载构造

每侧结构由以下层叠形成：

```text
模块侧 | 3 mm 内侧承力框 | 6.8 mm 腔（6 mm 腿） | 3 mm 外承力颊板 | 外侧
```

- 折腿材料为 `7075-T6`，名义厚度 `6 mm`；
- 内侧框和外颊板名义厚度均为 `3 mm`；
- 每侧四个 `6.8 mm` 隔柱把内外板连成结构盒，防止颊板在轴和止挡载荷下张开；机箱
  `(y,z)` 坐标为 `(-160,39)`、`(-160,68)`、`(-70,34)`、`(42,34)` mm；
- 外颊板主片下缘由 `z=30 mm` 降到 `z=24 mm`，使两只 `z=34 mm` 隔柱外圆到板边仍有
  `5 mm` 名义实体；理想 2001 点二维扫掠要求每个 Ø10 隔柱与折腿、钢脚跟、脚垫至少保留
  `2 mm` 名义净距；
- 名义裸机总宽为 `567.6 mm`；
- 主轴为 `Ø8 × 12.8 mm` 双剪切轴；光杆应跨越两个剪切面，螺纹不得位于剪切面内；
- 工作承载止挡为另一根 `Ø8 × 12.8 mm` 双剪切实体销；
- 腿根设置 `6 × 3 × 16 mm` 钢制脚跟承压面，使止挡反力不直接长期压溃铝腿边缘；
- `Ø5 × 12.8 mm` 锁销只负责防止工作位意外反折，并提供储存锁定位，不承担主要支撑反力。

### 2.1 运输盖让位

运输态不覆盖 V0.4 的 `DeepTravelLid_70mmClearance.SLDPRT`，而是使用独立的
`DeepTravelLid_V06_StandRelief.SLDPRT`。它仍为 1.5 mm 5052-H32 折弯盖、保持 70 mm
线缆净空；左右侧回边分别切出 `y=-155..41 mm、z=5..15 mm` 的让位槽，覆盖折叠腿
名义 `y=-147..33 mm、z=8..70 mm` 包络并保留约 8 mm 的 Y 向、3 mm 的 Z 向静态余量。
该 V0.6 运输装配的 SOLIDWORKS 离散干涉结果为零；连续折叠、公差、密封/锁扣和样机
运输冲击仍属于未完成的实物验证。

正式工作载荷路径应为：桌面 → 氯丁橡胶脚垫（CAD 候选）→ 7075-T6 折腿 → 钢脚跟承压面 → Ø8 实体
止挡 → 内外侧板和隔柱 → 机箱。主轴保持转动中心，锁销保持状态；二者都不能替代宽面实体
承载止挡的功能。

## 3. 支撑几何

| 项目 | 名义值 |
| --- | ---: |
| 主轴至脚垫中心距 | `170 mm` |
| 橡胶脚垫 | `Ø16 × 6 mm` 圆冠 |
| 脚垫中心距桌面 | `8 mm` |
| 模块面相对桌面 | 约 `60°` |
| 预计腿旋转角 | 约 `92.423°` |
| 预计后支撑深度 | 约 `133.770 mm` |

圆冠脚垫允许小角度接触自适应，但必须有机械卡持或等效的防脱构造，不能只依赖胶粘剂。
两侧脚垫中心、前侧机箱支承和实际桌面接触点共同决定三维支撑多边形；只看侧视图深度不能
证明侧向稳定。

## 4. 抗倾覆筛查

当前筛查输入为：

- 满载质量：`20 kg`；
- 最不利操作力：`20 N`；
- 操作点高度：`300 mm`；
- 对操作倾覆力矩采用安全系数：`1.5`。

按早期静力筛查，要求重心投影距相应支撑边界至少：

`20 N × 300 mm × 1.5 ÷ (20 kg × 9.81 m/s²) ≈ 45.87 mm`

`133.770 mm` 支撑深度的理想中点为 `66.88 mm`。满载纵向重心目标为该中点附近
`±20 mm`，对应理论最小边界余量约 `46.88 mm`。该目标只比筛查需求多约 `1.01 mm`，
所以它不是可以直接吸收制造、摩擦、线缆和操作不确定性的“宽裕结论”。实物若不能达到
三维重心目标，必须调整支承几何或质量分配，而不是降低验收载荷。

## 5. 止挡载荷筛查

以单腿 `400 N`、`1.5` 倍静载系数和接触法向到主轴的 `28.0 mm` 止挡有效力臂筛查时，
实体止挡附近的反力约为：

`400 N × 1.5 × 170 mm ÷ 28.0 mm ≈ 3.64 kN`

该数值用于确定 Ø8 止挡、钢脚跟面、内外颊板、隔柱和紧固件的局部设计量级。它不等于
允许额定载荷，也没有包含孔承压、公差偏载、销轴弯曲、板张开、冲击、疲劳、材料批次和
装配预紧等全部因素。量产前必须补全解析校核、必要的有限元和实物试验。

## 6. 锁止与失效安全

V0.6 只保留一个正式展开角度，可减少半啮合和选错档位的风险。机构应满足：

1. 腿先压到 Ø8 实体承载止挡，再由 Ø5 锁销完全啮合；
2. 工作载荷增大时，主反力继续压紧止挡，而不是剪切 Ø5 锁销；
3. 锁销未完全啮合时应有清晰视觉或触觉反馈；
4. 解锁动作应防误触，且用户不用把手指伸入夹点；
5. 收纳位有独立锁定位，搬运和跌落时腿不能自行展开；
6. 主轴、止挡和锁销都应有可靠轴向防脱，紧固件应有可检验的防松方案；
7. 轴套/衬套应隔离销轴与阳极铝孔的长期磨损，磨损件应可更换。

## 7. 必须完成的验证矩阵

| 项目 | 最低验证内容 | 主要观察量 |
| --- | --- | --- |
| 三维重心 | 最重模块、电源、线缆、盖锁全部装入；正常及最坏偏载 | 重心投影、支撑边界余量、左右偏移 |
| 摩擦/滑移 | 目标桌面材料，干燥及合理污染状态 | 起滑力、脚垫滚动或爬移、残余位移 |
| 操作稳定 | 最不利位置/方向施加 `20 N` | 倾覆、滑移、抬脚、结构弹性位移 |
| 偏载与侧向 | 单腿 `400 N`，叠加 `30 N` 侧向 | 永久变形、孔椭圆化、侧板张开、销轴弯曲 |
| 静载 | 目标额定工况的 `1.5` 倍并保持 | 止挡接触、钢脚跟压痕、隔柱和紧固件松动 |
| 折叠寿命 | 至少 `10000` 次完整折叠 | 间隙增长、轴套磨损、锁销啮合、止挡压痕 |
| 脚垫保持 | 拉脱、扭转、反复接触和污染后复检 | 机械卡持、防脱、开裂、永久压缩 |
| 公差链 | 板厚、阳极层、平面度、孔位、隔柱、销轴和轴套 | 无卡死、无过度游隙、止挡同时接触 |
| 防松/防脱 | 循环、运输振动和维护拆装后 | 扭矩保持、销轴轴向位移、锁固标记 |
| 跌落/运输 | 按最终产品运输边界制定工况 | 腿自行展开、锁销损坏、侧板变形、功能复检 |

任一工况出现滑移、倾覆、抬脚、永久变形、锁销半啮合、止挡失去同时接触或脚垫脱落，
都应视为需要重新设计，而不是通过增加说明标签放行。

## 8. CAD 与实物证据边界

V0.5 的最终软件验证结果为 `524 PASS / 15 WARNING / 0 FAIL`。它证明 V0.5 报告覆盖的
文件、引用、零件计数及离散 CAD 几何条件满足，是 V0.6 的双剪切结构基线；它不证明
V0.5 或 V0.6 的连续运动、结构强度、摩擦、疲劳、跌落或满载稳定性。

V0.6 当前独立只读验证统计为 **579 PASS / 13 WARNING / 0 FAIL**，完整统计和检查范围只以
[`reports/layout-v06-validation.md`](../reports/layout-v06-validation.md) 为准。WARNING 包括
SOLIDWORKS 打开时的 NeedsRegen 提示、两个有意保留的电源/模块包络交叠，以及尚未完成的
重心、摩擦、载荷、疲劳、公差、供应商件和连续运动实物边界。零 FAIL 仍不等于结构认证或
实物稳定性通过，且第 7 节实测不可省略。
