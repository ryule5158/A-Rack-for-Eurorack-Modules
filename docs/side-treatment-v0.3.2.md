# Rack4Modules V0.3.2 侧面处理与提手冻结说明

版本：V0.3.2；单位：mm。

本文冻结机箱材料厚度、提手数量以及左右侧面的外观与功能边界。它用于后续三维模型、
二维工程图和打样 DFM 统一，不代表散热、承载、跌落或实物装配已经验证完成。

## 1. 本次冻结结论

1. 外盖采用 `5052-H32` 铝板，名义厚度 `1.5`。
2. 主壳采用 `5052-H32` 铝板，名义厚度 `2.0`。
3. 左右侧框采用 `6061-T6` 铝合金，名义厚度 `3.0`。
4. 全机只设置一个搬运提手，位于顶部 / 上后沿中央；“顶部中央”和“上后沿中央”描述的
   是同一个提手，不得据此建立两个零件。
5. 左右侧面不设置提手、提手孔、提手安装耳或装饰性假提手。
6. 左右侧面继续保留内藏折叠支脚，并增加低调、左右镜像对称的散热孔。
7. 侧面散热孔的数量、尺寸、节距、圆角、开孔率和内部防护件尚未冻结；只有“低调、
   对称、不得与既有机构干涉”的原则在本版本冻结。

若其他旧文档或旧 CAD 中存在侧面提手、两个搬运提手、侧面大面积散热窗或不同材料厚度，
均以本文 V0.3.2 冻结项为准。

## 2. 材料及板厚边界

| 分区 | 冻结材料 | 名义厚度 | 制造意图 |
| --- | --- | ---: | --- |
| 外盖 / 可拆运输深盖 | 5052-H32 | 1.5 | 轻量折弯外盖；保持既有插线净空与四点内锁 |
| 主壳钣金 | 5052-H32 | 2.0 | 宽背板、上下边及主体折弯壳的基础厚度 |
| 左右侧框 | 6061-T6 | 3.0 | 承担导轨端部、折叠支脚及盖锁附近的局部结构连接 |

5052-H32 适用于主壳和外盖的折弯组织；具体内弯半径、K 因子、折弯扣除、轧制方向和
回弹由钣金厂在展开图签发前确认。6061-T6 侧框优先采用型材加 CNC 或经 DFM 认可的加工
方式，不得未经复核直接按 5052 的小半径折弯工艺处理。

材料名称和板厚冻结不等于结构强度已经通过。散热孔加入后，侧框净截面、应力集中、
提手载荷路径、支脚支撑和导轨端部刚度均需重新检查。

## 3. 唯一顶部提手

### 3.1 位置与数量

整机唯一搬运提手位于上后沿中央，处于左侧音频接口区与右侧 MIDI / USB-C / 电源盲板
区之间。该提手应保持折平、低外廓，并通过上后沿加强件或主承力结构传递载荷。

冻结规则如下：

- 总数量为 `1`。
- 不在左侧面或右侧面复制提手。
- 不在外盖上增加第二个搬运提手。
- 不以侧面开槽模拟握持孔；侧面孔只承担通风功能。
- 提手折平和提起时不得遮挡八个 TRS、三个 DIN、USB-C、独立电源盲板或相应线缆。
- 提手载荷不得由可换接口小板或单层未加强薄板独立承担。

V0.3.2 沿用中央 `128` 宽提手预留区、`126` 参考握把宽和 `110` 参考安装孔距。每侧
约 `1` 的理论净空仍需计入表面处理、装配偏差、安装耳和动态扫掠后复核，不能视为已经
完成供应商五金适配。

### 3.2 侧面无提手

左右侧面只组织折叠支脚、内藏盖锁、导轨端部连接和低调散热孔。侧面不得出现：

- 搬运提手本体或提手凹槽。
- 提手安装螺钉、压铆螺母或加强耳。
- 仅为模仿竞品外观而设置的假提手轮廓。
- 会被用户误认为抓握位置的大型贯通开窗。

这一限制用于减少重复五金、避免干涉折叠支脚和盖锁，并维持简洁、对称的侧面外观。

## 4. 左右侧面折叠支脚

左右侧面各保留一条内藏折叠支脚。收纳状态下支脚外缘应与机身侧面齐平，不得增加运输
外宽；当前最终横向中心为 `x = ±271`，纵向参考为 `y = -56`，外缘控制在 `x = ±274`。

支脚继续以约 `15° / 30°` 两档工作姿态作为项目目标，但最终转轴、止挡、展开角度、
摩擦脚垫、载荷和抗倾覆性能必须依据实际五金和整机重心验证。不得为增加散热孔而削弱：

- 支脚凹槽四周的连续承力边。
- 转轴、轴承或紧固件的孔边距。
- 两档止挡块及其受压区域。
- 支脚展开和收回的完整扫掠空间。
- 支脚载荷传到侧框和主壳的连接路径。

## 5. 低调对称侧面散热孔

### 5.1 设计原则

左右侧框增加镜像对称的散热孔阵列。散热孔应表现为低调的窄槽、小圆孔或经 DFM 确认的
等效几何，不采用贯穿大部分侧面的单个大窗，也不形成容易抓握或勾挂线缆的开口。

左右孔阵列必须满足：

- 相对于机身中心镜像，孔数、形状、节距和边距一致。
- 从正常使用视角看排列简洁，不压过唯一中央提手和上后沿接口带的视觉层级。
- 所有切口去毛刺；手可触区域采用安全圆角或倒角。
- 保持足够槽间筋宽、板边距和角部连续材料。
- 内侧如需防尘网、冲孔内衬或防异物结构，应作为独立可维护件评估，不得未经验证声称
  已达到特定 IP 防护等级。
- 两侧都必须实际通风；不得只加工装饰盲槽后称为完成散热设计。

### 5.2 强制避让区

散热孔在出二维加工图前，必须与最终总装进行剖面和动态干涉检查，并避开以下区域：

1. **折叠支脚凹槽及机构**：包括收纳腔、转轴、止挡、紧固件、加强片和支脚全过程扫掠。
2. **四个内藏盖锁**：左右各两个；避开锁体、锁舌、弹簧、安装孔、加强区及开闭运动范围。
3. **六根导轨端部**：避开导轨端连接块、侧框螺纹、M3 紧固件及 104HP 模块边界。
4. **侧框边缘和主壳连接**：避开折边、压铆件、角码、接缝、螺钉以及工厂要求的最小孔边距。
5. **上后沿接口结构**：避开左侧八个 TRS、中央提手、右侧三个 DIN、USB-C、独立电源
   盲板的安装件、插头和内部线束弯折空间。
6. **后部 VESA 承力结构**：避开中央 VESA 100 加强板、横梁、立柱、紧固件和载荷传递路径。
7. **电源及母线禁入体积**：中央 PSU 区和分布式母线区未定型前，孔阵列不得妨碍未来
   线束、绝缘、屏蔽或防护结构。
8. **深盖搭接和密封边**：孔位不得进入盖边搭接、缓冲垫、锁舌接触和运输防护所需实体区。

不得以“左右看起来对称”为由忽略两侧内部零件可能不同；最终孔位必须先分别检查左、右
实物结构，再确认镜像方案成立。

### 5.3 尚未冻结的孔型参数

以下项目需要热设计、结构评审和工厂 DFM 后另行冻结：

- 单孔形状、长度、宽度、直径和端部圆角。
- 每侧孔数、排数、节距、阵列边界及实际开孔率。
- 冲孔、激光切割、CNC 或其他加工方式。
- 内衬网、防尘、液体泼溅和异物触及措施。
- 表面处理前后的孔边质量和颜色处理。
- 侧面孔与既有下沿两组隐藏通风之间的进出风路径。

因此，V0.3.2 冻结“应设置低调、左右对称的侧面散热孔”，但不授权工厂依据经验自行决定
孔尺寸和孔位。正式加工必须等待带尺寸工程图。

## 6. 竞品直接参考与项目定制的区分

### 6.1 可明确追溯的竞品布局参考

本项目对 Intellijel 7U Performance Case Gen-2 和 Befaco 7U Case 的直接参考，限于已有
官方资料能够支持的高层功能组织：

- 后向窄长边集中布置信号接口和电源入口，而宽背板保留给 VESA。
- 搬运提手位于后向窄长边的中央区域。
- Intellijel 的折叠支架收纳在左右侧面，并具有使用角度定位。
- Intellijel 深盖采用分布在左右侧面的多个锁点。
- VESA 100 位于机身宽背面，而不是与后向接口混装在同一小板上。

这些参考仅支持布局原则，不代表 Rack4Modules 与任一竞品的孔位、支脚、锁扣、提手、
Joiner、接口板或配件机械兼容。

### 6.2 用户允许的 Rack4Modules 项目定制

以下内容属于用户允许并在本项目内冻结或继续设计的定制，不应写成竞品原厂结构：

- `3 × 104HP`、无 1U 的总体模块构成。
- 外盖 `5052-H32 1.5`、主壳 `5052-H32 2.0`、侧框 `6061-T6 3.0` 的材料组合。
- 全机仅一个顶部 / 上后沿中央提手，明确取消侧面提手。
- 左右侧面在保留折叠支脚的同时增加低调、镜像对称散热孔。
- 下沿两组隐藏被动通风与侧面通风协同的散热路径。
- 独立、无电源功能孔的电源盲板，以及尚未确定的内部电源禁入体积。

不得使用竞品商标、外观图或手册推导未公开的内部尺寸，也不得宣称本项目侧面散热孔是
竞品原厂设计、官方兼容件或已经由竞品验证的结构。

## 7. 出图与验证门槛

侧面工程图签发前至少完成：

1. 在最终装配中分别显示左右侧框、支脚、锁扣、导轨端、接口后部和 VESA 加强结构。
2. 建立支脚收纳/两档展开及四个锁扣开闭的动态包络。
3. 根据上述避让区绘制候选散热孔，再核对左右镜像及最小实体筋宽。
4. 让钣金/CNC 工厂确认 3 厚 6061-T6 的孔边距、刀具圆角、去毛刺和表面处理能力。
5. 使用完整材料和孔阵列执行结构复核；必要时对支脚、导轨端和盖锁载荷进行有限元分析。
6. 在电源、模块功耗和机箱姿态确定后完成热仿真或样机温升测试。
7. 用真实提手、支脚、锁扣和深盖进行装配、搬运、倾覆、疲劳及运输验证。

当前尚未完成侧面散热孔的热性能验证、开孔后侧框强度验证、支脚承载实测、提手载荷实测
或整机运输验证。V0.3.2 是设计冻结和后续出图依据，不是上述验证已经通过的声明。
