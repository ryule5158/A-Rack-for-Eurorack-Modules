## 横向结论

- 便携轻量产品普遍把市电隔离放在认证外置适配器中；Doepfer/Pittsburgh 的箱内市电方案对应更重、更深或偏固定式结构。V11 的“外置低压适配器 + 箱内分配/DC-DC 待定”方向合理。
- 商业导轨通常是刚性铝挤压件配钢制 M3 条，并在轨端连接到刚性侧框。可靠性取决于真实型材、端孔、直线度、首孔、螺纹条及侧框装配，不取决于渲染中看起来粗细。V11 自制轨必须按自己的图纸、试件和拉拔/挠度试验验收。
- 盖子的商业实现从 PET-G 加绑带到深铝盖加四点锁止都有。V11 的四锁扣、导向回边、金属压缩限位在 CAD 中形成了完整载荷链，但零干涉不能替代锁盖吊装、振动、跌落和循环试验。
- 折脚可以内嵌、外部框架或附件化，没有唯一商业布局。V11 应按双剪轴、实体止挡、位置锁、脚垫摩擦和循环寿命验收，不能仅凭“藏在壳内”判定可靠。
- I/O 既可位于后缘，也可位于窄边 utilities row。V11 把 I/O 放到上侧窄边是已冻结的用户体验选择，不应宣传成 Eurorack 唯一标准。

## V11 当前差距

截至本次复核，没有从官方产品对比中发现一个还能凭公开资料直接确定、且必须继续修改的纯 CAD 几何缺陷。继续削薄导轨、外侧脚架夹板、连杆或盖锁路径没有依据，并会违背可靠性优先。

仍不能宣称“与商业产品同等可靠”。必须补齐真实供应商件 STEP/安装图、钣金/焊接/机加工/表处 DFM、公差链和紧固件可达性；制造工程样机后完成满载与偏载、单腿侧载、1.5×静载、10000 次支脚/锁盖循环、提手吊装、VESA 拉脱、振动/跌落、摩擦污染、真实模块首件、带插线合盖、热/接地/EMC/电气安全试验。
