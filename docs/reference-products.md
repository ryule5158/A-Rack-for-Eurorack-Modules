## 重要边界

以上产品资料用于机械构型比较，并不表示本工程与这些厂商的专有 I/O 板、电源、固件或机械零件直接兼容。所有连接器真实开孔必须等最终采购料号确定后依据原厂 CAD 或数据表复核。
